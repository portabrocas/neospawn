## Install
Put `neospawn-0.24.1.jar` in your `mods` folder, replacing any older `neospawn-*.jar`. GeckoLib for NeoForge 1.21.1
(4.9.x) is still required.

## Fixed in 0.24.1
- **The Gobbler dropped nothing** in packs with Cataclysm, the Undergarden, the Aether or Iron's Spells. Those mods
  add their own item rarities, and the treasure roll crashed on them, which threw away the Gobbler's whole drop
  (its Jaw, Arcade Tokens and XP too). Modded rarities now count as epic, and a failed treasure roll can no longer
  take the rest of the loot with it.
- **Quest book (NeoSpawnPack):** about half the quests showed as "Unnamed" with their links missing. FTB Quests
  replaces any id from 8000000000000000 up, so those quests lost their titles and dependencies. Every id is now in
  range. Reinstall the quest book with `tools/install-quests.ps1` (it backs up the old one). Progress on the
  affected quests starts over; the rest keep theirs.
