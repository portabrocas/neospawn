# NeoSpawn roster

Every OreSpawn (1.7.10) mob and ore, paired with its original NeoSpawn equivalent.
Equivalents fill the same role (biome, size, behavior), but names, models, art and code
are new. Real animals and mythic creatures keep their common names; invented OreSpawn
names get new ones.

Status: ✅ in game · 🔜 next phase
